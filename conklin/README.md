# Work with AI — handout

**`Work-with-AI.pdf`** is the current one-page handout. It's in the Conklin Arcade beta poster style: English at the top, then Spanish, French and Swahili in three columns, and a strip at the foot in all four languages.

- `build-with-ai.html` holds the page and all its text. Edit it, then run `bash build-with-ai.sh` to print it to PDF with headless Chrome. On Windows, Chrome uses Segoe UI as the poster does; this build machine fell back to Inter.
- `assets/` holds the Conklin logo: `conklin-logo-dark.png` is for light pages, `conklin-logo-white.png` for dark ones.

**Review before printing:** a native speaker should check the Spanish, French and Swahili, Swahili especially.

The other PDFs and scripts in this folder are earlier drafts.
