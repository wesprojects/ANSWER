# AI Questions — one-page handout

One page per language, in Conklin's standard order: English, Spanish, French, Swahili.

- `AI-Questions-EN.pdf`, `-ES.pdf`, `-FR.pdf`, `-SW.pdf` — the finished sheets (US Letter).
- `content.py` — all the text. Edit here, then run `python3 build_pdf.py` to rebuild every PDF.
- `assets/conklin-logo-white.png` — Conklin logo, taken from wesprojects/VTRANSLATE.

**Review before printing:** the Spanish, French and Swahili text is a draft. Have a native speaker check it, Swahili especially.
