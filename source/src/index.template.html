DATA

HOW THE BOM IS BUILT

Panels — a panel is a shared junction at each end, a base horizontal frame package (2 bars, top cap, base trims), skins both sides (skin height = panel height − 6"), then stackers, power, glass. A panel package replaces frame package + 2 fabric skins when it fits (p66, p390).

Junctions — same-height junctions and two-height change-of-height junctions use the pre-configured style numbers (p344–358). Three or more heights use Build Your Own: posts, blocks, light seals, trims, cap, aligners (p33–38). Stacking omits the base junction trim and orders full-height trims separately (p26, p345).

Trims follow the exposed-face rule (p43): one panel at a height → end-of-run trim, two adjacent → L, two along a spine or three → T, 120° → 120°/V trims. Cap: one tallest panel → 90° change-of-height cap (aligners = panels at the second height), otherwise 90° cap (aligners = panels at the cap). All 120° junctions take a 120° cap.

Oval — the junction is the tallest height at a change-of-height, the lower panel gets a shortened top cap, and standard change-of-height trims (slim or cable-routing) fill the step (p80–81). Stacking junctions include their trim (p84).

LIMITS ENFORCED

Max 36" stacked per base panel, max two stackers, max 90" total (p27). Wall-start not at 30"H (p14). Skins total = height − 6" (p13). 18"W = pass-through only (p163). 72"W fabric horizontal only (p434). Runs over 8' without a return (p126). Seismic note over 72" (p124). Frameless glass thin only, top screens oval only, omit/spanning top caps thin only.
