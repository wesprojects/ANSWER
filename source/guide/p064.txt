Duo, c:scape, and Elective Elements Storage Units That Can Be Used with Answer 
Top Cap Mounting Brackets
Universal tie plates
(TS7TIEPLATE) can be
used to help align two 
storage units mounted in-line
with no gap between them.
Two tie plates should be
used, one near each edge.
When using with Duo or
Elective Elements storage,
the hardware shipped with
the plates can be used.
When used with c:scape
storage, pan head self drilling
fasteners should be ordered
from the service parts 
catalog (853108629MP).
