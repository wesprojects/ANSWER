Stability Guidelines, continued
Guidelines for Sliding Panel Door Applied to Answer
 
Host Panel
• Height of host panel must match height of door.
• Match the width of the host panel to the width of the door.
•  If host panel run exceeds 4', a junction stabilizer bracket must be 
applied to the door end of the host panel run. On long host panel 
runs, apply a junction stabilizer bracket or perpendicular panel 
every 8'. 
Receiving Panel
• Height of receiving panel must match height of door.
• If receiving panel run exceeds 4', a junction stabilizer bracket 
 must be applied to the door end of the receiving panel run. 
 On long receiving panel runs, apply a junction stabilizer 
 bracket or perpendicular panel every 8'.
